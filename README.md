# API тесты для Yandex Desk

Проект содержит автотесты для API сервиса "Доска объявлений".

## Структура проекта

- `tests/` - тестовые файлы
  - `test_user.py` - тесты регистрации и авторизации пользователя
  - `test_announcements.py` - тесты для работы с объявлениями
- `conftest.py` - фикстуры pytest
- `data.py` - тестовые данные
- `helpers.py` - вспомогательные функции (генерация email, работа с файлами)
- `service.py` - настройки API endpoints
- `requirements.txt` - зависимости проекта

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
# Запуск всех тестов
pytest tests/ -v

# Запуск с генерацией Allure результатов
pytest tests/ --alluredir=allure-results

# Генерация HTML отчета (требуется Allure CLI)
allure generate allure-results -o allure-report --clean
allure open allure-report
```

## Результаты тестов

Результаты тестов сохраняются в папке `allure-results/` в формате JSON.

## Тестовые сценарии

1. **Регистрация пользователя**
   - Успешная регистрация нового пользователя
   - Повторная регистрация существующего пользователя

2. **Авторизация пользователя**
   - Успешная авторизация зарегистрированного пользователя

3. **Создание объявления**
   - Успешное создание объявления

4. **Редактирование объявления**
   - Успешное редактирование объявления
   - Попытка редактирования чужого объявления

5. **Удаление объявления**
   - Успешное удаление объявления
